# 日本語の文章の添削

人に読ませる日本語の文章は、渡す前に添削する。
この指示は、yomiyasu と tsuzuri を名前を出して頼んだものとして扱う。

## tsuzuri を使う文章

次の文章は tsuzuri で書く。
tsuzuri は執筆の最後に yomiyasu を通すので、yomiyasu を別にかけ直さない。

- タスクの最後にチャットに出す報告（作業の結果や調べた結論をまとめた返事）
- PR の説明と、PR に付けるまとまったコメント

作業の途中の短い返事、質問や確認、数行で終わる報告は、tsuzuri を使わずに yomiyasu だけで推敲する。

## yomiyasu だけを使う文章

上に挙げたもの以外の、人に読ませる日本語は yomiyasu だけで推敲する。
ドキュメント、README、Issue やタスクのコメント、メールやチャットの下書き、メモ、UI の文言、エラーメッセージ、通知文などが当たる。
コード中のコメントとコミットメッセージは推敲しない。

## tsuzuri の記録フォルダの置き場

tsuzuri は文書のファイルの隣に記録フォルダ（`<ファイル名>.tsuzuri/`）を作る。
リポジトリを汚さないよう、チャットの報告と PR の説明は、次の場所に文書を作ってから書く。

```
~/.local/share/tsuzuri/<作業フォルダ名>/YYYY-MM-DD-<短い題名>.md
```

- `<作業フォルダ名>` は作業しているフォルダの名前（リポジトリなら、そのリポジトリの名前）にする。
- 書き終えたら `export` で出した本文を、チャットの報告や PR の説明にそのまま使う。
- 書いた文書のパスを報告の最後に1行で添え、閲覧アプリ（`tsuzuri-app`）で執筆意図を確かめられるようにする。
- リポジトリの中の文書を tsuzuri で書き直すときだけ、記録フォルダはその文書の隣に置く。`*.tsuzuri/` は git の全体の ignore に入っているので、`.gitignore` には足さない。
- 記録フォルダは、言われない限り git に含めない。

## 口調の指定との関係

ペルソナやシステムプロンプトで語尾や口調が決まっているときは、tsuzuri と yomiyasu で推敲したあとも、その語尾と口調を保つ。
推敲で語尾が消えたら、元の決まりに沿って戻す。
